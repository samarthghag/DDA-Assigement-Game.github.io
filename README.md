# Number Guessing Game

A fun and interactive number guessing game built using HTML, CSS, and JavaScript, implementing the Divide and Conquer algorithm strategy.

## 🎮 Game Features

- **Dynamic Range**: The game's number range is determined by the player's name length (minimum range is 1-10)
- **Lives System**: Players get 3 lives to guess the correct number
- **Smart Hints**: Receives a strategic hint on the last life using the Divide and Conquer approach
- **Responsive Design**: Beautiful UI that works perfectly on both desktop and mobile devices
- **Interactive Feedback**: Clear messages indicating if guesses are too high or too low
- **Score Tracking**: Keeps track of the number of attempts made

## 🚀 How to Play

1. Visit the game at: https://samarthghag.github.io/DDA-Assigement-Game.github.io/
2. Enter your name to start the game
3. The game will generate a random number based on your name length
4. Try to guess the number within 3 attempts
5. You'll receive a helpful hint on your last life
6. Use the feedback (too high/too low) to guide your guesses
7. Try to win with the fewest attempts possible!

## 🔧 Technical Implementation

### Divide and Conquer Strategy
- Used in random number generation
- Implemented in the hint system to divide the possible number range
- Helps players make more informed guesses

### Technologies Used
- HTML5
- CSS3 (with Flexbox for responsive layout)
- JavaScript (ES6+)
- Object-Oriented Programming principles
